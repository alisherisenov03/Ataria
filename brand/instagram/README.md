# Instagram ATARIA — что куда выкладывать

Папки пронумерованы в порядке загрузки. Внутри каждой папки файлы тоже по порядку (01, 02, …) — выкладывайте в этом порядке.

| Папка | Что это | Куда в Instagram |
|---|---|---|
| `1_Иконки_Актуального/` | 5 обложек-иконок | Обложки закреплённых сторис (Актуальное) |
| `2_Актуальное_сторис/1_Рецепты` … `5_Вопросы` | Сторис по рубрикам | Выложить в сторис и добавить в соответствующее Актуальное |
| `3_Сторис_Знакомство/` | 8 сторис | Обычные сторис, по одной в день или серией |
| `4_Обложки_Reels/` | 9 обложек | Обложка при публикации рилса |
| `5_Карусели/1_Карусель_6_в_1`, `2_Карусель_Детали` | Слайды 4:5 | Один пост-карусель на папку, слайды по порядку |

`story_photos/` — исходники без текста, `_превью/` — листы для проверки, их не выкладывать.
