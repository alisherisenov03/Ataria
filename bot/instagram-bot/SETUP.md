# Instagram-бот ATARIA: подключение

Бот уже выложен: `https://pepexjsboutlqmqjyemc.supabase.co/functions/v1/instagram-bot`.
Он молчит, пока не заполнены 3 секрета ниже (ключ Claude уже стоит от WhatsApp-бота).

## Что он делает
- **Креаторы.** Вы пишете первое сообщение блогеру сами, с телефона. Бот видит его и считает чат
  «креаторским». Когда блогер ответит, бот продолжает: объясняет бартер, предлагает идею ролика,
  собирает ФИО, город, адрес и телефон для отправки, ставит статус в таблице `ugc_leads`.
  Если блогер есть в списке (`ugc_leads`), чат тоже считается креаторским.
- **Покупатели.** Все остальные, кто пишет в Direct: консультирует, оформляет заказ, даёт ссылку Kaspi Pay.
- Ваши сообщения, написанные вручную, бот видит и учитывает. Остановить бота в конкретном чате:
  скажите ассистенту «останови бота с @ник».
- Что требует вас (отправить подушку, создать промокод, жалоба): таблица `wa_handoffs`,
  строки с `ig:` в поле phone. Ассистент присылает сводку раз в день.

## 1. Аккаунт Instagram
Instagram должен быть профессиональным: Настройки → Тип аккаунта и инструменты → «Аккаунт автора» или «Бизнес».
В приложении Instagram: Настройки → Сообщения и ответы на истории → Подключённые инструменты →
включить **«Разрешить доступ к сообщениям»**.

## 2. Приложение Meta (то же, «Jarvis Ataria»)
developers.facebook.com → Мои приложения → Jarvis Ataria → слева **Instagram** →
**«Настройка API со входом через Instagram»** (API setup with Instagram login).
1. **Сгенерировать маркеры доступа** → «Добавить аккаунт» → войти в Instagram ATARIA → разрешить.
   Появится маркер (длинная строка) → это `IG_TOKEN`. Бот сам продлевает его каждые 30 дней.
2. На той же странице: **Секрет приложения Instagram** (Instagram app secret) → это `IG_APP_SECRET`.
   Внимание: это не тот секрет, что для WhatsApp.
3. **Настройка вебхуков** (Configure webhooks):
   - Callback URL: `https://pepexjsboutlqmqjyemc.supabase.co/functions/v1/instagram-bot`
   - Verify token: любое слово, например `ataria-insta-2026` → это `IG_VERIFY_TOKEN`
   - Сначала добавьте секреты (шаг 3 ниже), потом «Проверить и сохранить».
   - Подписаться на поле **messages**.
4. У строки с вашим аккаунтом включить переключатель **«Webhook subscription»**, если он есть.

## 3. Секреты в Supabase
supabase.com → проект → Edge Functions → Secrets → добавить:

| Имя | Значение |
|---|---|
| `IG_TOKEN` | маркер из шага 2.1 |
| `IG_APP_SECRET` | секрет приложения Instagram из шага 2.2 |
| `IG_VERIFY_TOKEN` | придуманное слово из шага 2.3 |

Ключи никому не пересылайте, в том числе в чат. Они вводятся только в Supabase.

## 4. Проверка
С другого аккаунта (друг, второй аккаунт) напишите в Direct ATARIA «Здравствуйте, какую подушку посоветуете?».
Бот должен ответить за несколько секунд. Если нет — напишите ассистенту, он посмотрит логи.

Если сообщения от посторонних людей не доходят, а от аккаунтов с ролью в приложении доходят,
Meta требует расширенный доступ к `instagram_business_manage_messages` (App Review). Тогда подадим заявку.
