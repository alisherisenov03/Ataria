## Что это

Статический сайт-инструкция для покупателей кухонной машины ATARIA AT-SM23 (Kaspi). Первый экран — выбор техники: слева комбайн, справа аэрогриль («скоро»). Далее страница машины в стиле Bork, насадки, скорости, 21 рецепт с пошаговым режимом, таймером, push-уведомлениями и выбором порций.

## Как устроено

- Генератор: `guide/tools/build.mjs` (Node). Данные: `guide/content.json` (RU) + `guide/content.kk.json` (перевод, накладывается по ключам и индексам; новые рецепты добавлять в оба файла в одном порядке).
- Сборка: `cd guide && node tools/build.mjs` → HTML в `guide/` (корень `/`, `/kk/`, `/sm23/...`, `/airfryer/`). Картинки в HTML автоматически получают `?v=<хеш>` (кэш не мешает).
- Стили: `guide/style.css`; скрипты: `guide/site.js` (поиск, порции, режим готовки, таймер, push), `guide/anim.js` (Motion), `guide/sw.js` (service worker для уведомлений).
- Проверка: `python3 -m http.server 4173` в `guide/` + Playwright (Chromium предустановлен).
- Деплой: Vercel, команда `team_GqKAboNJ4hAC2TOF0mc0T4BK`, проект `ataria-guide` (`prj_JIYp1bpXo5n4PmoKFTBDA2KYaifn`), rootDirectory `guide`. Деплой через `create_deployment` с gitSource github `alisherisenov03/Ataria`, ref — ветка выше, target production. Сначала commit + push.

## Push-уведомления таймера

- Supabase проект `pepexjsboutlqmqjyemc`. Таблицы `guide_push_config` (ключи VAPID, только сервис) и `guide_timers`; функция `guide_push_tick()`; cron `guide-push-tick` каждые 10 с.
- Edge function `guide-push` (verify_jwt false), код в `supabase/functions/guide-push/index.ts`. Публичный VAPID-ключ в `guide/site.js`. Приватный ключ — только в таблице Supabase, в репозиторий не класть.
- Запись в БД через MCP требует подтверждения пользователя; если окно не доходит, давать SQL для Supabase SQL Editor.

## Фото и стиль (важно)

- Стиль сайта — как у Bork: тёплый тёмный тауп (`--bg #2B2421`), заголовки Unbounded 300, текст Montserrat, акцент латунь `#C8A06A`. Блоки «зигзаг»: макро-кадр + короткий текст.
- Пользователю понравились светлые «архитектурные» кадры: машина в профиль на каменном подиуме у изогнутой стены с вертикальными рёбрами, тауп, мягкий свет, мука в воздухе (`img/m-side.jpg`), и макро-кадры функций со светом (`img/t-*.jpg`). Слишком тёмные кадры (чёрный зал) — не нравятся. Рецепты — разные гармоничные палитры (не всё коричневое).
- Генерация: Higgsfield `gpt_image_2_5`, quality high, resolution 2k, с референсами. Логотип ATARIA нейросеть рисует плохо: проси пустую голову без надписей и накладывай настоящий логотип (вырезан с фото `014.jpg`, выровнять по наклону). Шкалу скоростей тоже накладывай с реального фото (`006.png` без подсветки, `005.png` с синей подсветкой): P на ~10:30, 0 сверху, 1–6 по часовой, 6 на ~7 часов.
- Насадки в работе висят из головы машины вниз в чашу (воротник сверху). Не путать с заводскими фото, где они стоят перевёрнутые.
- Факты от владельца: таймер до 15 мин, шаг 30 с; крюк скорость 1–2, венчик и лопатка 1–6; мясорубка 1–6, не перегружать, чистить шнек от жира; боковой разъём под крышкой с треугольником (поднять вверх); насадки надевать на вал и поворачивать до щелчка; рычаг головы к открытому замочку, голова фиксируется вверху, вниз — защёлкивается сама; тестораскатка 8 уровней; мощность 2000 Вт, чаша 7 л. Максимум муки за раз — неизвестен, не писать.

## Что осталось / идеи

1. Видео в стиле Bork: делать с нуля. Варианты: (а) Wan 2.6 / Kling в Higgsfield, ~7,5 кредита за 5 с (цену проверять); (б) 3D-модель машины в Blender (простые формы + настоящие текстуры логотипа, значков и шкалы) и рендер роликов — точнее и без «нейросетевых» ошибок, но дольше. Обсудить с владельцем.
2. Аэрогриль: нет фото и модели — справа сейчас заглушка. Попросить фото/название.
3. Блок габаритов (чертёж) и таблица характеристик, как у Bork — нужны размеры и вес.
4. Нужна ли цена и кнопка «Купить на Kaspi» на первом экране — спросить.
5. Казахские тексты проверить носителю языка.
