# Настройка голоса (ElevenLabs)

Голос слышит и говорит, а думает и действует Jarvis-бэкенд. Агент ElevenLabs получает один инструмент `ask_jarvis`, который отправляет запрос в `POST {backend}/chat`.

## 1. Создать агента
elevenlabs.io → **Agents** → **Create agent** → пустой шаблон.

- **Язык:** русский (при необходимости добавь казахский).
- **Модель (LLM):** любая быстрая, ей нужно только передавать запрос.
- **Голос:** выбери по вкусу.
- **System prompt:**

```
Ты Jarvis, голосовой помощник Алишера. Говори по-русски, коротко и живо.
На любую просьбу, кроме приветствия и уточнения, вызывай инструмент ask_jarvis, передавая слова пользователя как есть.
Ответ инструмента проговори своими словами, не добавляя ничего от себя.
Никогда не придумывай данные и не отвечай сама на вопросы про цифры, контакты и дела.
```

## 2. Добавить инструмент (Tools → Add tool → Webhook)
- **Name:** `ask_jarvis`
- **Description:** «Передать просьбу пользователя главному агенту Jarvis и получить ответ».
- **Method:** POST
- **URL:** `https://<адрес-бэкенда>/chat`
- **Headers:** `Authorization` = `Bearer <BACKEND_TOKEN>`
- **Body parameters:**
  - `text` (string, обязательный): «Дословная просьба пользователя»
  - `session_id` (string): значение `alisher`
- Ответ бэкенда: `{"reply": "..."}`, говорить нужно поле `reply`.

## 3. Безопасность агента
В настройках агента включи **Require authentication** (подпись ссылки). Тогда подключиться к нему можно только через бэкенд (`/voice/session`), а не по одному ID.

## 4. Скопировать ID
Из адреса или настроек агента возьми Agent ID и положи в Railway как `ELEVENLABS_AGENT_ID`.
