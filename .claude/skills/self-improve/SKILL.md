# Self-improve loop

## After each task
1. List corrections from Alisher in this task (his words, briefly).
2. For each: is it a one-off, or a rule? Rules go to `jarvis.memory` as `lesson` or `preference` (via memory-keeper rules) and, if it is about how I work, into the relevant skill file.
3. Slow spots: name the step that cost the most time and the fix (cache, parallel calls, a ready tool).
4. If a skill was used and failed, run skill-reviewer on that skill.

## Standing lessons (already learned)
- Be short, give direct links, do not repeat instructions, do not ask for data that already exists (cabinet, Kaspi, Higgsfield, memory).
- If one way fails, do the next thing right away.
- Check generated product images against the real reference before showing them; show only good ones.
- Exact numbers come from the source, never estimates.
