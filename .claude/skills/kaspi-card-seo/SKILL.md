# Kaspi card improvement

1. Pull the top 5 competitor cards for the main query (kaspi_market.search): titles, photo count and style, rating, reviews.
2. Title: product type + key spec + size/volume + brand, words buyers type (e.g. "ортопедическая подушка с эффектом памяти 40x60"). No caps spam.
3. Photos: first photo product on clean background, then in use, dimensions, details, box. Generate with higgsfield-product-shots and pass ataria-design-check.
4. Description: benefits first, then specs, care, warranty, delivery.
5. Reviews: ask satisfied buyers (draft text only; sending needs Alisher's "да").
Output: concrete before/after text and a photo list. Alisher edits the card in the Kaspi cabinet.
