Спереди

Тестораскатка

Раскатывает тесто в ровный пласт. 8 режимов толщины: от толстого для лепёшек до самого тонкого для беша и лапши.

Подходит для

Тесто для бешбармакаЛапша для лагманаТесто для мантов и пельменейЛазанья

Как пользоваться

  1. Начните с самого толстого режима.
  2. Пропустите тесто, сложите пополам и пропустите ещё раз.
  3. Уменьшайте толщину по одному шагу, пока не получите нужную.

Совет

  • Слегка присыпайте тесто мукой, чтобы не липло к валикам.
  • Для беша обычно хватает предпоследнего режима.

Чего не делать

  • Не мойте валики под водой: протрите сухой щёткой и тканью.
